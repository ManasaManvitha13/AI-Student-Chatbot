# **EduBot-AI**

## 🎓 Overview  
The **AI Student Chatbot** is an intelligent assistant designed to help students access academic information quickly and interactively. Built with a clean UI and a modular backend, the chatbot uses NLP techniques to understand user queries and respond with relevant information.

This project demonstrates practical experience in:  
- Natural Language Processing  
- Model training and evaluation  
- Backend API development  
- Frontend UI/UX design  
- Git branching workflows  
- Deployment‑ready architecture  

---

## 📁 Project Structure  

```
AI-Student-Chatbot/
│
├── Backend+Frontend/
│   ├── __init__.py
│   ├── models/
│   │   ├── app.py
│   │   ├── chatbot.py
│   │   ├── chatbot_Application_model.h5
│   │   ├── intents.json
│   │   ├── labels.pkl
│   │   ├── words.pkl
│   │   ├── training.py
│   │   ├── static/
│   │   │   ├── Script.js
│   │   │   ├── Style.css
│   │   └── templates/
│   │       └── index.html
```

### 🔍 Explanation  
- **Backend/models/chatbot.py** — Core NLP logic and model inference  
- **training.py** — Script to train the chatbot model  
- **intents.json** — Dataset of intents, patterns, and responses  
- **app.py** — Flask backend serving the chatbot API  
- **templates/index.html** — Main UI page  
- **static/Script.js** — Handles chat interactions  
- **static/Style.css** — UI styling

## ✨ Features  

### 🧠 NLP‑Powered Understanding  
- Intent classification using a trained neural network  
- Tokenization, bag‑of‑words, and pattern matching  
- Customizable intents and responses  

### ⚡ Fast & Responsive  
- Preloaded model for quick inference  
- Smooth UI with typing animation  
- Instant message rendering  

### 🎨 Clean & Modern UI  
- Student‑friendly design  
- Chat bubble layout  
- Responsive styling  
- ECE‑themed branding  

### 🔌 Modular Backend  
- Flask API  
- Easy to extend with new endpoints  
- Clear separation of concerns  

### 🗂️ Easy to Customize  
- Add new intents in `intents.json`  
- Retrain model with `training.py`  
- Modify UI in `templates` and `static`
